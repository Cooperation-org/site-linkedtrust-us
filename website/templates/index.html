Frequently asked questions

What is LinkedTrust?

LinkedTrust is a public benefit corporation run by the workers using earned governance, based in Tucson, Arizona. We build verified trust systems, civic tech platforms, and AI-powered tools for organizations that care about doing things right.

What is LinkedClaims?

LinkedClaims is the open standard LinkedTrust builds on. It makes claims, credentials, and testimonials verifiable and linkable on a public trust graph, so trust can be earned and checked rather than simply asserted.

What does LinkedTrust build?

We build verified trust systems, civic tech platforms, verifiable credentials and badges, AI integrations like RAG search and document extraction, and full-stack MVPs in React, Svelte, Django, and FastAPI.

Where is LinkedTrust based?

LinkedTrust is headquartered in Tucson, Arizona, with a global team spanning several continents, including developers across the US, Nigeria, Ethiopia, India, and Pakistan.

How is LinkedTrust different?

We are a public benefit corporation run by the workers using earned governance. Every team member shares equity. Our work is backed by a verifiable track record of LinkedClaims, so the testimonials on this site are claims you can independently verify.
